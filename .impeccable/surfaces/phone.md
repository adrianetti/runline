# Phone recording and run history

Mode: Operate. The user pinned a simple monotone interface with few words and one sporty free icon set. Use native Android Material structure, neutral day/night role resources, and the pinned Tabler outline icons. Distance, Time and Pace /km lead; the short state says Ready, Recording, Paused or Run recovered.

Start takes one tap once required Android permissions/settings are satisfied. Recording offers Pause; paused/recovered runs offer Resume and Finish. Discard moves to the menu and retains a confirmation. The ready screen omits an empty route panel. A saved run puts Share to Strava after the route; export, file share, elapsed/sample details and deletion remain available in the overflow menu.

A shield action exposes Recording protection and Android settings. Preserve necessary permission, storage and recovery messages; reducing copy must not hide failures. Icons support labels or have accessible names. Use 64dp main actions, native font scaling, paired night colors and system Back. Route lines are real GPS samples with gap boundaries, not a basemap or decorative illustration.

Sharing is a GPX-save/website handoff, not an account connection or one-tap upload. No uploaded state is inferred. Local recovery is separate from continuous capture: no route can be recorded while the phone is powered off, and internal copies are not cloud backup.
